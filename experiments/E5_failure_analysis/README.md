# Eksperimen E5 — Failure Case Analysis

## 1. Tujuan Ilmiah
Melakukan audit mendalam terhadap kasus-kasus kegagalan sistem (*retrieval errors*) pada kondisi derau tinggi untuk mengidentifikasi kelemahan mendasar representasi audio.

## 2. Target Evaluasi
* Mengaudit minimal 20 kasus kegagalan riil (kombinasi *false positive* dan *false negative*).
* Mengelompokkan penyebab kegagalan:
  1. Low SNR Masking (sinyal vokal tertutup derau latar).
  2. Spectral/Feature Overlap (tumpang tindih pita frekuensi).
  3. Inter-Species Acoustic Similarity (kemiripan struktur vokal antar taksa).
  4. Durasi vokal terlalu pendek / energi rendah.
* Diagnosis ditulis secara analitis per kueri tanpa kalimat templat berulang.

## 3. Status Pelaksanaan
**TERJADWAL / BELUM DILAKUKAN** (Tahap Minggu 3 / H19–H20).
